모아 캘린더 위젯

Google Calendar·Google Tasks와 카카오 톡캘린더·할 일을 Chrome 오른쪽 사이드패널에서 한눈에 확인하고 관리하는 확장프로그램입니다.

주요 기능

  • 월간 캘린더와 날짜별 일정·할 일 통합 표시
  • 일정과 할 일 등록, 상세 보기, 수정, 완료 및 삭제
  • 여러 캘린더의 표시 여부와 저장 위치 선택
  • 캘린더 색상, 라이트·다크·시스템 테마 지원

Google 사용자 데이터 사용

사용자가 명시적으로 권한을 허용한 경우에만 Google Calendar와 Google Tasks 데이터를 조회하거나 사용자의 요청에 따라 변경합니다. 이 데이터는 캘린더 및 할 일 기능 제공에만 사용되며 개발자 서버, 광고 또는 분석 서비스로 전송되지 않습니다.

별도의 회원가입이나 개발자 서버 없이 작동합니다. 인증과 데이터 처리는 사용자의 Chrome 브라우저와 Google·카카오 공식 API 사이에서 이루어집니다.
