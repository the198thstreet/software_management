앱 이름: 어르신을 위한 쉬운 길찾기

패키지 이름: com.senioreasyroute.app

개발자/운영자: 어르신을 위한 쉬운 길찾기 운영자

시행일: 2026년 7월 26일

개인정보 문의: czerny2k@naver.com

이 개인정보 처리방침은 어르신을 위한 쉬운 길찾기 Android 앱이 사용자 데이터에 접근, 사용, 전송, 보관 및 삭제하는 방식을 설명합니다.

이 앱은 회원가입, 로그인, 결제, 광고 기능을 제공하지 않으며 개발자가 운영하는 중앙 서버나 사용자 데이터베이스를 사용하지 않습니다.

현재 위치를 이용한 길찾기와 지도 표시를 위해 사용자의 위치와 경로 요청 정보가 카카오 지도 서비스로 전송될 수 있습니다. 위치 권한을 허용하지 않아도 장소를 직접 검색하여 앱의 주요 기능을 사용할 수 있습니다.

1. 처리하는 데이터

앱은 길찾기 기능 제공을 위해 아래 데이터를 처리할 수 있습니다.

데이터 유형 처리 방식 이용 목적
대략적인 위치 및 정확한 위치 사용자가 현재 위치 사용 또는 실시간 길안내 기능을 선택하고 Android 위치 권한을 허용한 경우에만 위치를 확인합니다. 위치 좌표는 주소 확인, 지도 표시 및 경로 검색을 위해 카카오 지도 서비스로 전송될 수 있습니다. 현재 위치를 출발지로 설정하고, 지도에서 현재 위치를 표시하며, 이동 중 경로 진행 상황과 목적지 도착 여부를 안내하기 위해 사용합니다.
장소 검색어, 장소명, 주소 및 좌표 사용자가 입력한 검색어와 선택한 장소의 이름, 도로명 주소, 지번 주소 및 좌표가 장소 검색과 경로 계산을 위해 카카오 지도 서비스로 전송될 수 있습니다. 출발지와 도착지를 검색하고, 위치를 지도에 표시하며, 이동 경로를 찾기 위해 사용합니다.
경로 요청 및 길안내 정보 선택한 출발지, 도착지, 이동수단 및 경로 옵션을 이용해 경로를 요청하고, 반환된 이동 시간, 거리, 환승 및 단계별 안내 정보를 앱 화면에 표시합니다. 도보, 버스, 지하철, 자전거 등의 경로와 단계별 길안내를 제공하기 위해 사용합니다.
집 및 즐겨찾는 길 정보 사용자가 직접 저장을 선택한 장소명, 주소, 좌표, 출발지, 도착지 및 이동수단 정보가 앱 전용 저장공간에 저장됩니다. 이 정보는 개발자 서버로 전송되거나 개발자 계정에 연결되지 않습니다. 집으로 가기와 즐겨찾는 길을 다시 빠르게 이용할 수 있도록 하기 위해 사용합니다.
기기 방향 및 센서 정보 길안내 중 사용자가 바라보는 방향을 지도에 표시하기 위해 기기의 회전 및 방향 센서 값을 기기 안에서 처리합니다. 센서 원본값은 개발자 서버에 저장하거나 전송하지 않습니다. 지도 위 방향 화살표와 사용자가 바라보는 방향을 표시하기 위해 사용합니다.

2. 위치정보 이용과 선택권

  • 위치정보는 사용자가 현재 위치 또는 실시간 위치 기능을 선택한 경우에만 사용합니다.
  • 앱은 백그라운드 위치 권한을 요청하지 않으며, 앱이 화면에 표시되어 길안내를 제공하는 동안에만 실시간 위치를 이용합니다.
  • 사용자는 Android 설정에서 언제든지 위치 권한을 변경하거나 철회할 수 있습니다.
  • 위치 권한을 허용하지 않아도 출발지와 도착지를 직접 검색하여 길을 찾을 수 있습니다.
  • 현재 위치는 길안내 기능을 제공하는 데 필요한 동안 메모리에서 처리되며, 사용자가 직접 집 또는 즐겨찾기로 저장하지 않는 한 앱의 영구 저장공간에 보관하지 않습니다.

3. 데이터 전송 및 제3자 서비스

앱은 개인정보를 판매하지 않으며, 개발자가 운영하는 서버나 데이터베이스에 사용자 정보를 업로드하지 않습니다. 다만 앱 기능 제공 과정에서 다음 서비스가 데이터를 처리할 수 있습니다.

  • 카카오맵 SDK 및 카카오 REST API: 지도 표시, 장소 검색, 주소 확인 및 경로 검색을 위해 위치 좌표, 장소 검색어, 장소명, 주소, 출발지, 도착지, 이동수단 및 일반적인 네트워크 요청 정보가 처리될 수 있습니다.
  • Google Play services 위치 서비스: 사용자가 위치 권한을 허용한 경우 기기의 현재 위치를 확인하기 위해 사용합니다.
  • 카카오맵 앱: 사용자가 앱 안의 카카오맵 안내 시작 버튼을 직접 누르면 출발지와 도착지 정보가 카카오맵 앱으로 전달될 수 있습니다.
  • GitHub Pages: 이 개인정보 처리방침 페이지를 제공하는 과정에서 IP 주소, 접속 시각, 브라우저 및 사용자 에이전트와 같은 일반적인 웹 요청 정보가 처리될 수 있습니다.
  • 법적 요구: 관련 법령, 법원 또는 수사기관의 적법한 요청이 있는 경우 법률이 요구하는 범위에서 정보가 제공될 수 있습니다.

제3자 서비스에서 처리하는 데이터에는 각 서비스의 약관과 개인정보 처리방침이 적용될 수 있습니다.

  • 카카오 개인정보 처리방침
  • Google 개인정보처리방침
  • GitHub 개인정보 보호정책

4. 기기 내 보관 및 삭제

  • 집 및 즐겨찾는 길은 사용자가 저장을 선택한 경우에만 앱 전용 저장공간에 보관됩니다.
  • 저장한 집 또는 즐겨찾는 길은 앱에서 제공하는 삭제 기능으로 개별 삭제할 수 있습니다.
  • Android 설정에서 앱 데이터를 삭제하거나 앱을 삭제하면 기기에 저장된 집, 즐겨찾는 길 및 앱 설정 정보가 함께 삭제됩니다.
  • 회원 계정이 없으므로 계정 삭제 절차는 필요하지 않습니다.
  • 카카오, Google 및 GitHub가 처리하는 데이터의 보관과 삭제는 각 서비스의 정책에 따릅니다.

5. 보안

앱은 기능 제공에 필요한 최소한의 데이터만 처리하며, 네트워크 통신에는 HTTPS를 사용합니다. 앱의 네트워크 보안 설정은 암호화되지 않은 일반 HTTP 통신을 허용하지 않습니다.

집과 즐겨찾는 길은 Android 앱 전용 저장공간에 보관되며 다른 앱에서 일반적인 방법으로 직접 접근할 수 없습니다.

6. 광고, 분석 및 사용자 추적

앱은 광고 SDK, 맞춤 광고, 사용자 행동 분석 SDK 또는 개발자 자체 추적 서비스를 사용하지 않습니다. 앱은 광고 식별자를 이용해 사용자를 추적하거나 사용자 프로필을 만들지 않습니다.

7. 아동의 개인정보

앱은 고령자의 편리한 길찾기를 주목적으로 하며 아동을 대상으로 하지 않습니다. 개발자는 아동의 개인정보를 고의로 수집하지 않습니다.

8. 개인정보 처리방침 변경

앱 기능, 관련 법령, Google Play 정책 또는 제3자 서비스가 변경되는 경우 이 개인정보 처리방침을 수정할 수 있습니다. 중요한 변경이 있는 경우 이 페이지의 시행일 또는 최종 업데이트일을 갱신합니다.

9. 문의

개인정보 처리, 위치정보 이용, 기기 내 데이터 삭제 또는 이 개인정보 처리방침에 대한 문의는 czerny2k@naver.com으로 연락해 주세요.

Senior Easy Route Privacy Policy

App name: Senior Easy Route (어르신을 위한 쉬운 길찾기)

Package name: com.senioreasyroute.app

Developer/Operator: Senior Easy Route Operator

Effective date: July 26, 2026

Privacy contact: czerny2k@naver.com

This Privacy Policy explains how the Senior Easy Route Android app accesses, uses, transmits, retains, and deletes user data.

The app does not provide account registration, login, payment, or advertising features. The developer does not operate a central server or user database for this app.

When the user chooses location-based routing, location and route request data may be transmitted to Kakao map services. Users can still search for places manually without granting location permission.

1. Data We Process

Data type How it is processed Purpose
Approximate and precise location Accessed only when the user selects current location or live guidance and grants Android location permission. Coordinates may be sent to Kakao map services for address lookup, map display, and route search. To set the current location as the starting point, display live position, calculate route progress, and check arrival near the destination.
Place search terms, place names, addresses, and coordinates Search terms and selected place information may be sent to Kakao map services for place search and routing. To search for starting points and destinations, display them on a map, and find routes.
Route request and guidance information The app uses the selected starting point, destination, transport mode, and route options to request a route and display returned travel time, distance, transfers, and step-by-step directions. To provide walking, bus, subway, bicycle, and step-by-step route guidance.
Home and favorite routes Place names, addresses, coordinates, route endpoints, and transport mode are stored in app-specific device storage only when the user chooses to save them. To provide quick access to Home and favorite route features.
Device orientation and sensor data Rotation and orientation values are processed on the device to show the direction the user is facing. Raw sensor values are not stored on or transmitted to a developer-operated server. To display the heading arrow and map orientation during guidance.

2. Location Use and User Choice

  • Location is used only after the user selects a current-location or live-location feature.
  • The app does not request background location permission. Live location is used while the app is visible and providing route guidance.
  • Users can change or revoke location permission at any time in Android settings.
  • Users can manually search for a starting point and destination without granting location permission.
  • Current location is processed in memory as needed and is not persistently stored unless the user explicitly saves a place as Home or a favorite route.

3. Data Transmission and Third-Party Services

The app does not sell personal data or upload user data to a developer-operated server or database. The following services may process data while providing app features.

  • Kakao Maps SDK and Kakao REST APIs: May process coordinates, place search terms, place names, addresses, route endpoints, transport mode, and ordinary network request information to provide maps, search, address lookup, and routing.
  • Google Play services location services: Used to obtain the device's current location after the user grants permission.
  • KakaoMap app: If the user explicitly selects the KakaoMap guidance button, starting point and destination information may be passed to the KakaoMap app.
  • GitHub Pages: May process ordinary web request information such as IP address, access time, browser, and user agent when serving this Privacy Policy page.
  • Legal requirements: Information may be provided when required by applicable law, court order, or a valid government request.

Each third-party service may process data according to its own terms and privacy policy.

  • Kakao Privacy Policy
  • Google Privacy Policy
  • GitHub General Privacy Statement

4. On-Device Retention and Deletion

  • Home and favorite routes are retained in app-specific device storage only when the user chooses to save them.
  • Users can delete saved Home or favorite routes using the deletion controls provided in the app.
  • Clearing the app's data in Android settings or uninstalling the app deletes Home, favorite routes, and app settings stored on the device.
  • The app does not create user accounts, so there is no account deletion process.
  • Retention and deletion of data processed by Kakao, Google, or GitHub are governed by their respective policies.

5. Security

The app processes only the minimum data needed to provide its features and uses HTTPS for network communication. Its network security configuration does not permit unencrypted cleartext HTTP traffic.

Home and favorite routes are stored in Android app-specific storage, which is not normally accessible to other apps.

6. Advertising, Analytics, and Tracking

The app does not use advertising SDKs, personalized advertising, user behavior analytics SDKs, or developer-operated tracking services. It does not use an advertising identifier to track users or build user profiles.

7. Children's Privacy

The app is designed primarily to help older adults navigate more easily and is not directed to children. The developer does not knowingly collect children's personal information.

8. Changes to This Policy

This Privacy Policy may be updated due to changes in app features, laws, Google Play policies, or third-party services. Material changes will be reflected by updating the effective date or last updated date on this page.

9. Contact

For questions about data processing, location use, on-device deletion, or this Privacy Policy, contact czerny2k@naver.com.
