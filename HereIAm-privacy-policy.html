이 개인정보 처리방침은 저 여기 있어요 Android 앱이 사용자 데이터에 접근하고 이를 사용, 전송, 보관 및 삭제하는 방식을 설명합니다.

앱은 회원가입, 로그인, 결제 또는 광고 기능을 제공하지 않으며, 개발자가 운영하는 사용자 계정 서버나 사용자 데이터베이스를 사용하지 않습니다.

앱은 사용자가 위치 찾기를 실행하고 권한을 허용한 경우에만 기기의 현재 위치를 확인합니다. 좌표를 주소로 변환하고 지도를 표시하기 위해 카카오의 API와 지도 SDK를 사용하며, 위치 메시지는 사용자가 문자 또는 공유 기능을 직접 선택한 경우에만 선택한 외부 앱으로 전달됩니다.

1. 앱에서 처리하는 데이터

앱은 위치 확인 및 가족과의 위치 공유 기능을 제공하기 위해 다음 데이터를 처리합니다.

데이터 유형 처리 방식 이용 목적
가족 전화번호 사용자가 직접 입력한 전화번호를 Android 앱 전용 설정 저장공간에 보관합니다. 전화번호는 개발자 서버나 카카오로 전송되지 않습니다. 문자 앱의 수신인 또는 전화 앱의 통화 대상으로 미리 입력하여 사용자가 가족에게 연락하기 쉽게 하기 위해 사용합니다.
현재 위치 사용자가 위치 찾기를 실행하고 위치 권한을 허용한 경우, GPS 또는 네트워크 위치 제공자를 통해 현재의 위도, 경도 및 위치 정확도를 확인합니다. 위치는 앱 실행 중 메모리에서 처리되며 앱 전용 저장공간에 기록되지 않습니다. 현재 위치 확인, 지도 표시, 주소 확인 및 위치 공유 메시지 작성을 위해 사용합니다.
주소, 위치 확인 시각 및 정확도 카카오의 좌표-주소 변환 결과와 기기에서 확인한 시각 및 정확도를 앱 화면과 위치 공유 메시지에 표시합니다. 이 정보는 앱 전용 저장공간에 기록되지 않습니다. 사용자와 가족이 위치의 장소, 주소, 확인 시각 및 정확도를 이해할 수 있도록 하기 위해 사용합니다.
사용자가 공유하는 위치 메시지 메시지에는 장소명, 주소, 확인 시각, 정확도 및 위도·경도가 포함된 카카오맵 링크가 포함될 수 있습니다. 사용자가 문자 또는 공유 기능을 선택한 경우에만 Android가 선택된 외부 앱에 이 내용을 전달합니다. 앱은 메시지를 자동으로 발송하지 않습니다. 사용자가 가족 또는 직접 선택한 상대방에게 현재 위치를 알릴 수 있도록 하기 위해 사용합니다.
네트워크 요청 정보 카카오 API 및 지도 SDK와 통신할 때 IP 주소, 앱 또는 기기 관련 요청 정보와 같은 일반적인 네트워크 정보가 카카오에 의해 처리될 수 있습니다. 주소 변환, 지도 콘텐츠 제공, 서비스 보안 및 안정적인 통신을 위해 처리될 수 있습니다.

2. 위치 권한과 사용자 선택권

  • 앱은 현재 위치를 확인하기 위해 Android의 정확한 위치 또는 대략적인 위치 권한을 요청합니다.
  • 앱은 사용자가 화면에서 위치 찾기를 실행한 경우에만 포그라운드에서 위치를 확인하며, 백그라운드 위치 권한을 요청하지 않습니다.
  • 사용자는 위치 권한을 거부할 수 있습니다. 권한을 허용하지 않으면 위치 확인 및 위치 공유 기능을 사용할 수 없습니다.
  • 사용자는 Android 설정에서 언제든지 앱의 위치 권한을 변경하거나 철회할 수 있습니다.
  • 앱은 연락처, 문자 읽기·발송, 통화 실행, 카메라 또는 마이크 권한을 요청하지 않습니다. 문자와 통화는 사용자가 선택한 외부 앱의 작성 또는 확인 화면을 여는 방식으로 동작합니다.
  • 인터넷 권한은 주소 변환과 지도 표시를 위해 사용됩니다.

3. 데이터 전송 및 외부 서비스

개발자는 앱 사용자의 위치, 가족 전화번호 또는 공유 메시지를 수신하는 자체 서버를 운영하지 않으며, 개인정보를 판매하거나 광고 목적으로 사용하지 않습니다. 다만 앱의 핵심 기능을 위해 다음 외부 서비스 또는 앱으로 데이터가 전달될 수 있습니다.

  • 카카오 좌표-주소 변환 API 및 Kakao Maps SDK: 현재 위치의 위도와 경도는 주소를 확인하고 지도를 표시하기 위해 HTTPS로 카카오에 전송됩니다. 카카오가 처리하는 네트워크 정보와 데이터에는 카카오의 개인정보 처리방침이 적용됩니다.
  • Android 위치 서비스: 현재 위치는 사용자의 기기 설정과 Android 위치 제공자를 통해 확인됩니다. 기기 제조사, 이동통신사 또는 운영체제 제공자의 위치 처리에는 각 서비스의 정책이 적용될 수 있습니다.
  • 문자 및 공유 앱: 사용자가 문자 또는 공유 기능을 직접 선택하면 가족 전화번호와 위치 메시지 또는 위치 메시지가 사용자가 선택한 외부 앱으로 전달됩니다. 실제 발송 여부와 이후의 보관·처리는 사용자가 결정하며, 선택한 앱과 통신 서비스의 개인정보 처리방침이 적용됩니다.
  • 전화 및 지도 앱: 사용자가 통화 또는 지도 링크 열기를 선택하면 전화번호 또는 위치 링크가 해당 기능을 처리하는 외부 앱으로 전달될 수 있습니다.
  • 기기 클립보드: 문자 또는 공유 기능을 처리할 앱이 없는 경우, 앱은 사용자가 다른 앱에 붙여넣을 수 있도록 위치 메시지를 기기 클립보드에 복사할 수 있습니다. 클립보드의 보관과 접근은 Android 버전 및 기기 설정에 따라 달라집니다.
  • 개인정보 처리방침 웹 호스팅: 이 페이지를 제공하는 호스팅 사업자는 페이지 제공 과정에서 IP 주소, 접속 시각, 브라우저 및 사용자 에이전트와 같은 일반적인 웹 요청 정보를 처리할 수 있습니다.
  • 법적 요구: 관련 법령, 법원 또는 수사기관의 적법한 요청이 있는 경우 법률이 요구하는 범위에서 정보가 제공될 수 있습니다. 다만 개발자는 앱 사용자 계정 서버나 사용자 데이터베이스를 보유하지 않습니다.

4. 보관 및 삭제

  • 가족 전화번호는 사용자가 변경하거나 Android 설정에서 앱 데이터를 삭제하거나 앱을 삭제할 때까지 기기의 앱 전용 저장공간에 보관됩니다.
  • 가족 전화번호가 저장되는 앱 전용 설정은 Android 클라우드 백업 및 기기 간 전송 대상에서 제외되도록 구성되어 있습니다.
  • 현재 위치, 주소, 확인 시각 및 정확도는 앱 실행 중 메모리에서만 처리되며 앱 전용 저장공간에 지속적으로 저장되지 않습니다. 앱 절차를 완료하거나 앱 프로세스가 종료되면 앱 내 임시 상태에서 제거됩니다.

  • 앱은 회원 계정을 만들지 않으므로 별도의 계정 삭제 절차가 필요하지 않습니다.

5. 보안

Here I Am Privacy Policy

App name: Here I Am (저 여기 있어요)

This Privacy Policy explains how the Here I Am Android app accesses, uses, transmits, retains, and deletes user data.

The app does not provide account registration, login, payment, or advertising features. The developer does not operate an account server or user database for the app.

The app accesses the device's current location only after the user starts a location search and grants permission. It uses Kakao APIs and the Kakao Maps SDK to convert coordinates into an address and display a map. A location message is passed to an external messaging or sharing app only when the user explicitly chooses that action.

1. Data Processed by the App

The app processes the following data to provide location checking and family location-sharing features.

Data type How it is processed Purpose
Family phone number A phone number entered by the user is stored in Android app-specific settings storage. It is not sent to the developer's server or to Kakao. To prefill the recipient in the messaging app or the number in the phone app so the user can contact a family member more easily.
Current location When the user starts a location search and grants location permission, the app obtains the current latitude, longitude, and location accuracy through GPS or network location providers. The location is processed in memory while the app is running and is not written to app-specific persistent storage. To check the current location, display a map, determine an address, and compose a location-sharing message.
Address, check time, and accuracy The app displays the result of Kakao's coordinate-to-address conversion together with the time and accuracy determined on the device. This information may be included in a location-sharing message and is not written to app-specific persistent storage. To help the user and their family understand the place, address, time, and accuracy of the location.
Location message shared by the user The message may contain a place name, address, check time, accuracy, and a Kakao Map link containing latitude and longitude. Android passes this content to a selected external app only after the user chooses the messaging or sharing feature. The app does not automatically send the message. To let the user tell a family member or another recipient selected by the user where they are.
Network request information When the app communicates with Kakao APIs and the Kakao Maps SDK, Kakao may process ordinary network information such as the IP address and app- or device-related request information. To provide address conversion and map content, protect the service, and maintain reliable communications.

2. Location Permission and User Choice

  • The app requests Android precise or approximate location permission to determine the current location.
  • The app accesses location in the foreground only after the user starts a location search. It does not request background location permission.
  • Users may deny location permission. Location checking and location-sharing features will not work without it.
  • Users can change or revoke location permission at any time in Android settings.
  • The app does not request permission to access contacts, read or send SMS, place calls, use the camera, or use the microphone. Messaging and calling work by opening the compose or confirmation screen of an external app selected by the user.
  • Internet permission is used for address conversion and map display.

3. Data Transmission and External Services

The developer does not operate a server that receives users' locations, family phone numbers, or shared messages. The developer does not sell personal data or use it for advertising. Data may nevertheless be passed to the following external services or apps for core functionality.

  • Kakao coordinate-to-address API and Kakao Maps SDK: The current latitude and longitude are transmitted to Kakao over HTTPS to determine an address and display a map. Network information processed by Kakao is governed by Kakao's Privacy Policy.
  • Android location services: The current location is determined through the user's device settings and Android location providers. The policies of the device manufacturer, mobile carrier, or operating-system provider may apply to their processing.
  • Messaging and sharing apps: When the user explicitly selects messaging or sharing, the family phone number and location message, or the location message alone, are passed to the external app selected by the user. The user decides whether to send the content. Subsequent retention and processing are governed by the selected app and communications service.
  • Phone and map apps: If the user chooses to make a call or open a map link, the phone number or location link may be passed to the external app handling that action.
  • Device clipboard: If no app can handle messaging or sharing, the app may copy the location message to the device clipboard so the user can paste it elsewhere. Clipboard retention and access vary by Android version and device settings.
  • Privacy Policy web hosting: The provider hosting this page may process ordinary web request information, such as IP address, access time, browser, and user agent, while serving the page.
  • Legal requirements: Information may be provided where required by applicable law, a court order, or a valid government request. However, the developer does not maintain an app account server or user database.

4. Retention and Deletion

  • The family phone number remains in app-specific storage until the user changes it, clears the app's data in Android settings, or uninstalls the app.
  • App-specific settings containing the family phone number are configured to be excluded from Android cloud backup and device-to-device transfer.
  • The current location, address, check time, and accuracy are processed only in memory while the app is running and are not persistently stored in app-specific storage. They are removed from the app's temporary state after the app flow is completed or the app process ends.
  • Copies of a location message passed to a messaging app, sharing app, or clipboard may remain in the external app, communications service, or device feature. Retention and deletion are governed by that service's policy and the user's settings.
  • Information processed by Kakao while providing its API and map services is retained and deleted in accordance with Kakao's policies.
  • The app does not create user accounts, so no separate account-deletion procedure is required.

5. Security

The app uses encrypted HTTPS connections for Kakao APIs and map services and is configured not to allow unencrypted cleartext HTTP traffic. The family phone number is stored in Android app-specific storage and excluded from backup and device-to-device transfer.

After the user passes a location message to an external app or the clipboard, its security depends on that app, communications service, operating system, and the user's device settings.

6. Advertising, Analytics, and Tracking

The developer has not included advertising SDKs, personalized advertising, user-behavior analytics SDKs, crash-reporting SDKs, or a developer-operated tracking service in the app, and the app does not use an advertising identifier. Data processing by Kakao services used for address conversion and map display is described in Section 3 and governed by Kakao's Privacy Policy.

7. Children's Privacy

The app is a general-purpose tool for users who want to share their current location easily with family and is not primarily directed to children. The app does not verify age or create user accounts. If a child uses the app, location and phone-number data are processed in the same manner described in this Privacy Policy. The developer does not knowingly collect children's personal data on a developer-operated server.

This Privacy Policy may be updated due to changes in app features, external services, applicable laws, or Google Play policies. Material changes will be reflected by updating the effective date or last-updated date on this page.
