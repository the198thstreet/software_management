이 개인정보 처리방침은 ‘빠르고 심플한 한글(HWP/HWPX) 뷰어’ Android 앱이 사용자 데이터에 접근, 처리, 전송, 보관 및 삭제하는 방식을 설명합니다.

앱은 회원가입, 로그인 또는 결제 기능을 제공하지 않으며 개발자가 운영하는 사용자 서버나 데이터베이스를 사용하지 않습니다.

사용자가 선택한 HWP/HWPX 문서의 내용은 기기 안에서만 읽고 렌더링되며 개발자 서버 또는 광고 서비스로 업로드되지 않습니다.

2. 파일 및 저장공간 권한

  • 파일 선택기를 이용한 개별 문서 열기는 사용자가 직접 선택한 파일에 대한 읽기 권한만 사용합니다.
  • Android 11 이상에서 ‘기기에서 찾기’ 기능을 사용하려면 모든 파일 접근 권한이 필요할 수 있습니다. 이 권한은 공유 저장공간에서 HWP/HWPX 파일을 찾는 데만 사용합니다.
  • 모든 파일 접근 권한을 허용하지 않아도 파일 선택기 또는 다른 앱의 ‘연결 앱으로 열기’를 통해 문서를 볼 수 있습니다.
  • 사용자는 Android 설정에서 언제든지 모든 파일 접근 권한 또는 앱 권한을 변경하거나 철회할 수 있습니다.
  • 파일 선택기에서 허용한 지속적 읽기 권한은 최근 문서를 다시 열기 위해 Android가 보관할 수 있으며, 앱 데이터 삭제 또는 앱 제거 시 해제됩니다.

3. 데이터 이용 목적

  • 사용자가 선택한 HWP/HWPX 문서를 기기에서 해석하고 화면에 표시합니다.
  • 기기 공유 저장공간에서 지원되는 문서를 검색하고 파일명과 경로를 목록으로 제공합니다.
  • 최근 열었던 문서를 다시 선택할 수 있도록 파일명과 URI를 저장합니다.
  • 광고 제공, 광고 성과 측정, 분석 및 부정 사용 방지를 수행합니다.

4. 제3자 서비스와 데이터 공유

개발자는 문서 내용, 파일명, 파일 URI, 파일 경로 또는 최근 문서 기록을 자체 서버로 수집하거나 판매하지 않습니다. 다만 다음 서비스가 각각의 목적에 따라 데이터를 처리할 수 있습니다.

  • Google Mobile Ads SDK: 광고 제공, 분석 및 부정 사용 방지를 위해 IP 주소, 사용자 상호작용, 진단 정보와 기기 또는 계정 식별자를 처리할 수 있습니다. SDK가 전송하는 데이터는 전송 중 TLS로 암호화됩니다.
  • GitHub Pages: 이 개인정보 처리방침 페이지를 제공하는 과정에서 IP 주소, 접속 시각, 브라우저 및 사용자 에이전트와 같은 일반적인 웹 요청 정보가 처리될 수 있습니다.
  • 법적 요구: 관련 법령, 법원 또는 수사기관의 적법한 요청이 있는 경우 법률이 요구하는 범위에서 정보를 제공할 수 있습니다.
  • Google 개인정보처리방침
  • Google Mobile Ads SDK 데이터 공개 안내
  • GitHub 개인정보 보호정책

5. 광고와 사용자 선택

앱은 앱 실행 중 최초 문서를 여는 과정에서 전면 광고를 표시할 수 있습니다. 광고 표시 전에 앱 화면에서 안내하며, 광고가 종료되거나 준비되지 않은 경우 선택한 문서를 계속 엽니다.

광고 준비를 위해 Google Mobile Ads SDK가 앱 실행 중 초기화될 수 있습니다. 사용자는 Android 또는 Google 설정에서 광고 ID를 재설정·삭제하거나 광고 맞춤설정을 변경할 수 있습니다. 광고의 맞춤 여부와 동의 선택지는 사용자의 지역, Google 설정 및 적용 법령에 따라 달라질 수 있습니다.

6. 보관 및 삭제

  • 현재 열려 있는 문서 내용은 문서 표시를 위해 기기 메모리에서 처리되며 앱이 별도 문서 사본을 영구 저장하지 않습니다.
  • 기기 검색 결과는 검색 화면 제공을 위해 일시적으로 처리되며 개발자 서버에 저장되지 않습니다.
  • 최근 문서의 파일명과 URI는 사용자가 최근 목록에서 삭제하거나 Android 설정에서 앱 데이터를 삭제하거나 앱을 제거할 때까지 앱 전용 저장공간에 보관될 수 있습니다.
  • 회원 계정이 없으므로 계정 삭제 절차는 필요하지 않습니다.
  • Google 또는 GitHub가 처리하는 데이터의 보관 및 삭제는 각 서비스의 정책에 따릅니다.

7. 보안

문서와 최근 문서 기록은 기기 안에서 처리하며, 최근 문서 기록은 Android 앱 전용 저장공간에 보관됩니다. 광고 관련 네트워크 데이터는 Google Mobile Ads SDK를 통해 암호화되어 전송됩니다. 다만 전자적 처리 방식은 절대적인 보안을 보장할 수 없으므로 사용자는 민감한 문서가 저장된 기기와 앱 접근 권한을 안전하게 관리해야 합니다.

8. 아동의 개인정보

앱은 아동만을 대상으로 설계되지 않았으며 개발자는 아동의 개인정보를 고의로 직접 수집하지 않습니다. 보호자는 관련 문의 또는 삭제 요청을 아래 문의처로 보낼 수 있습니다.

9. 국외 처리

This Privacy Policy explains how the Android app “Fast and Simple HWP/HWPX Viewer” accesses, processes, transmits, retains, and deletes user data.

The app does not provide account registration, login, or payment features and does not use a developer-operated user server or database.

The contents of HWP/HWPX documents selected by the user are read and rendered only on the device and are not uploaded to a developer-operated server or advertising service.

1. Data We Process

Data typeHow it is processedPurpose

Document file name, file URI, and path The selected file name and URI may be stored in app-specific storage for the recent-documents feature. Advertising, device, and diagnostic information Google Mobile Ads SDK may automatically collect and share IP address (which may be used to estimate general location), interactions such as app launches, taps and ad video views, diagnostic information, and device or account identifiers such as Android advertising ID and app set ID. The app does not directly ask users to provide a name, phone number, email address, contacts, photos, precise location, microphone data, or camera data.

2. File and Storage Permissions

  • Opening an individual document through the system file picker uses read access only for the file explicitly selected by the user.
  • On Android 11 or later, the “Find on device” feature may require All files access. This permission is used only to locate HWP/HWPX files in shared storage.
  • Users can still open documents through the file picker or another app's “Open with” action without granting All files access.
  • Users can change or revoke All files access and other app permissions at any time in Android settings.
  • Android may retain read access granted through the file picker so that a recent document can be reopened. This access is removed when app data is cleared or the app is uninstalled.

3. Purposes of Processing

  • Parse and display HWP/HWPX documents selected by the user on the device.
  • Find supported documents in shared storage and show their file names and paths.
  • Store file names and URIs so users can select recently opened documents again.
  • Provide advertising, measure ad performance, perform analytics, and prevent fraud.

4. Third-Party Services and Data Sharing

The developer does not collect or sell document contents, file names, file URIs, file paths, or recent-document records through its own server. The following services may process data for their respective purposes:

  • Google Mobile Ads SDK: May process IP address, user interactions, diagnostic information, and device or account identifiers for advertising, analytics, and fraud prevention. Data transmitted by the SDK is encrypted in transit using TLS.
  • GitHub Pages: May process ordinary web request information such as IP address, access time, browser, and user agent when serving this Privacy Policy page.
  • Legal requirements: Information may be provided when required by applicable law, court order, or a valid government request.
  • Google Privacy Policy
  • Google Mobile Ads SDK data disclosure
  • GitHub General Privacy Statement

5. Advertising and User Choice

The app may show an interstitial ad when the first document is opened during an app session. The app provides an on-screen notice before the ad. After the ad is dismissed, or if no ad is ready, the selected document continues to open.

Google Mobile Ads SDK may initialize while the app is running to prepare an ad. Users can reset or delete their advertising ID or change ad personalization settings in Android or Google settings. Ad personalization and consent choices may vary by region, Google settings, and applicable law.

6. Retention and Deletion

  • The currently opened document is processed in device memory for display. The app does not permanently store a separate copy of the document.
  • Device scan results are processed temporarily to provide the results screen and are not stored on a developer-operated server.
  • Recent document file names and URIs may remain in app-specific storage until the user removes them from the recent list, clears app data in Android settings, or uninstalls the app.
  • The app does not create user accounts, so no account deletion process is required.
  • Data processed by Google or GitHub is retained and deleted according to each service's policy.

7. Security

Documents and recent-document records are processed on the device, and recent-document records are kept in Android app-specific storage. Advertising-related network data is transmitted in encrypted form through Google Mobile Ads SDK. However, no electronic processing method can guarantee absolute security, and users should securely manage devices and app permissions that can access sensitive documents.

9. International Processing
